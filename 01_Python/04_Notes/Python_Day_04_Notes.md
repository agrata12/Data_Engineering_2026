# 1. Randomisation

- Randomisation means generating or selecting something randomly.
- Programs can have a degree of unpredictability.
- Python provides the `random` module for randomisation.
- Python's random module uses the Mersenne Twister pseudo-random number generator (PRNG).
- Truly random numbers can be generated by measuring physical sources of randomness, such as electronic noise. This process is called sampling.
At each point, the next move is always unpredictable. 
- Random processes are non-deterministic, as they are impossible to determine in advance. Whereas machines are deterministic with their operations predictable and repeatable. 
- A deterministic process produces the same result when given the same starting conditions. A pseudo-random generator is deterministic because the same seed produces the same sequence.
- Algorithm by John Von Neumann in 1946 to create random number: 
    Algorithm mechanically simulates the scrambling affect of randomness.
    1. Select a truly random number called seed. This no can come from measurement of noise or current time in millisecond. 
    2. The seed is provided an input to a simple calculation. Square the seed and extract the middle digits of the resulting number to create the next seed.
    3. Use this output as next seed and repeat the process as many times needed. 
    Also called "middle squares method", introduced by John von Neumann.
    4. Randomness of numbers is dependent on the randomness of first seed only.
- Difference in randomly generated vs pseudo randomly generated:
    1. pseudo random sequence must eventually repeat (occurs when algo reaches a seed which is previously used). The length before the pseudo random sequence repeats is called "period".
    2. Key differnece: when you generate a number pseudo randomly, there are some sequence that never occur. 
- Python's random module is not suitable for cryptographic or security-sensitive applications. For security-related random values, Python provides the secrets module.

# 10. Stacks: 
The list methods make it very easy to use a list as a stack, where the last element added is the first element retrieved (“last-in, first-out”). To add an item to the top of the stack, use append(). To retrieve an item from the top of the stack, use pop() without an explicit index. 

eg:
stack = [3,4,5,6]
# stack.append(7)
stack.pop()
print(stack)
-----------------------------------
# 11. Lists as queue 

It is also possible to use a list as a queue, where the first element added is the first element retrieved (“first-in, first-out”);
- To implement a queue, use collections.deque which was designed to have fast appends and pops from both ends. 

from collections import deque
queue = deque(["Eric", "John", "Michael"])
queue.append("Terry")           # Terry arrives
queue.append("Graham")          # Graham arrives
queue.popleft()                 # The first to arrive now leaves
queue.popleft()                 # The second to arrive now leaves
print(queue)
